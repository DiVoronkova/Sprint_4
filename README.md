# h1 Тестирование приложения BooksCollector
===========================================
## h2 Проект содержит набор юнит-тестов для проверки работы класса BooksCollector. Тесты написаны на языке Python с использованием фреймворка pytest.
-----------------------------------------------------------------------------------

### h3 Файлы:
main.py — содержит исходный код класса BooksCollector.
tests.py — основной файл с тестами (класс TestBooksCollector).
conftest.py — содержит фикстуры для тестов (collection и ten_books_with_different_genres).
<hr>

### h3 Описание реализованных тестов:
1. Добавление книг в коллекцию (add_new_book)
test_add_new_book_three_correct_books_added
Проверка успешного добавления книг с корректными названиями (от 1 до 40 символов) в словарь books_genre.
test_add_new_book_incorrect_input_not_added
Негативная проверка: книги с некорректной длиной названия (0 или более 40 символов) не добавляются в коллекцию.
Параметризованный тест проверяет несколько вариантов некорректных названий.
2. Установка и получение жанров (set_book_genre, get_book_genre)
test_set_book_genre_genre_added
Проверка корректного установления жанра для книги из коллекции. Используется параметризация для проверки разных комбинаций книги и жанра.
test_get_book_genre_incorrect_genre_not_added
Негативная проверка: жанр не из допустимого списка не устанавливается, и метод get_book_genre возвращает пустую строку.
3. Фильтрация книг по жанрам (get_books_with_specific_genre)
test_get_books_with_specific_genre_true
Проверка вывода списка книг с указанным жанром. Используется параметризация для проверки разных жанров и количества книг в коллекции.
4. Получение полного словаря книг и жанров (get_books_genre)
test_get_books_genre_true
Проверка правильности формирования словаря books_genre. Тест подтверждает соответствие итогового словаря ожидаемому значению.
5. Детская библиотека (get_books_for_children)
test_get_books_for_children_books_with_age_rating_excluded
Проверка корректной фильтрации книг для детей. Из списка исключаются книги с жанрами "Ужасы" и "Детективы".
6. Работа с «Избранным» (favorites)
test_add_book_in_favorites_book_added
Проверка успешного добавления книги в список избранного.
test_delete_book_from_favorites_book_deleted
Проверка удаления книги из списка избранного. После удаления книга больше не присутствует в списке.
test_get_list_of_favorites_books_correct_list
Проверка получения полного списка книг, добавленных в избранное. Тест подтверждает, что метод возвращает все добавленные книги и исключает те, что не были добавлены в избранное.
